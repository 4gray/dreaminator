Dreaminator: installation

Windows 10 or 11 · Dreambox DM520 / OpenHDF · about 20 minutes

Install Dreaminator on your receiver, then manage IPTV playlists and favorite channels from a browser. Playlist synchronization preserves your existing satellite bouquets.

Receiver address::8088

Write the address from step 1 above. Replace RECEIVER-IP with it in the examples below. Application labels currently use Russian; this guide gives their English meaning.

Before you start

  • A compatible package named dreaminator_VERSION_all.ipk. Keep its full filename, including .ipk; Windows may hide that extension.
  • A FAT32 USB drive, a Windows computer on the same network, the receiver remote and a tablet or phone.
  • The receiver powered on or in standby, connected to the router.

Tested baseline: DM520, OpenHDF 6.4 build 137, Python 2.7.15. Current source build: 0.11.0-r3, built with Go 1.26.8+. The historical 0.6.0 release lacks the DM520 startup fixes and newer catalog features. See the repository setup guide before choosing a package. The package contains a MIPS executable despite its “all” label; ARM receivers are unverified.

1Find the receiver's network address

  1. On the remote, open MENU → Information → System information (sometimes called About or Receiver information).
  2. Find Network, for example eth0: 192.168.1.45 (100Mb/s).
  3. Write the IP address in the box on the first page.

If Network is empty or the address begins with 169.254, check the network cable and router connection.

2Copy the package to a USB drive

  1. Save the package in Downloads.
  2. Insert the USB drive. Press Win + E to open File Explorer, then select This PC.
  3. Right-click the USB drive → Properties. Check that File system says FAT32. If it says exFAT or NTFS, use another compatible drive or the network method later in this guide. Formatting a drive erases it; formatting is not required for these instructions.
  4. Copy the .ipk file directly to the USB drive, outside any folder.
  5. Right-click the drive → Eject, then unplug it.

3Install on the receiver

  1. Insert the drive into the receiver and wait about ten seconds.
  2. If asked to install extensions, press OK. Otherwise open MENU → Setup → Software management → Install local extension. Some images have an extra Software submenu.
  3. Select the USB drive (often /media/usb), then select dreaminator.
  4. Press OK or green and confirm installation. Wait for completion.
  5. Accept the GUI restart so Enigma2 loads the plugin. Remove the USB drive after installation.

Menu names vary. Look for “local”, “extension” or “IPK”. Installing over a previous version retains playlists and lists; back up receiver settings before upgrading.

4Open it on your computer

  1. Open Edge or Chrome.
  2. Enter http://RECEIVER-IP:8088 in the address bar, for example http://192.168.1.45:8088. Include http://.
  3. The Dreaminator page should appear. Use Ctrl + D to bookmark it.

The TV plugin shows the address and QR code under MENU → Plugins → Dreaminator → Settings. If Dreaminator is missing, use MENU → Shutdown → Restart GUI. With no configured sources, the plugin opens its settings screen directly.

If the page does not load, recheck the IP address and that both devices are on the same network. Wait for receiver startup and try again. Keep port 8088 on your trusted home network: the web interface has no login.

5Add a tablet shortcut and channels

  1. Connect the tablet to your home Wi-Fi.
  2. Scan the plugin's QR code or enter http://RECEIVER-IP:8088 in Chrome.
  3. On Android Chrome, open the three-dot menu → Add to Home screen → Add.
  4. Open Playlists → Add: paste a provider URL, upload M3U, enter Xtream credentials, or choose Stalker and enter the provider's portal/MAC.
  5. Choose groups/channels. A star adds a channel to a list; a group can become a separate list. Reorder items in My lists.
  6. Select Send to TV. Your selected channels appear in ordinary receiver bouquets alongside satellite channels. On TV tunes one channel immediately.

Adding a source does not create bouquets automatically. The native TV catalog can browse the source independently. Leave the receiver powered in standby for its 04:00 playlist/guide refresh.

6Enable the native programme guide

Do this once after the first Send to TV, allowing a few minutes for guide preparation.

  1. Open MENU → Plugins → EPG-Importer. If absent, press green in Plugins → Extensions → EPGImport and install it.
  2. In EPG-Importer press blue for Sources.
  3. Ensure Dreaminator is checked; save with green.
  4. Enable Automatic import at 05:00, after Dreaminator's overnight refresh.
  5. Press yellow for a manual import to populate programmes now.

The catalog also has its own guide. Native channel-list/infobar EPG uses EPGImport; unselected catalog channels can still have programme information.

Troubleshooting

USB drive not recognized: transfer over the network

If your receiver has FTP enabled, Windows can copy the package without a USB drive. Open Win + R → cmd. Replace both the filename and RECEIVER-IP below with your actual values:

curl -T "%USERPROFILE%\Downloads\dreaminator_VERSION_all.ipk" ^
  "ftp://root@RECEIVER-IP/tmp/" --user root

Enter the receiver password when prompted. If FTP is unavailable, use an SSH/SFTP client supported by your receiver image. After a successful transfer, install the local package from /tmp through the receiver's software menu. Files in /tmp disappear on reboot, so install before restarting.

The tablet shortcut stopped opening

The router may have assigned a different IP after a power outage. Check step 1 and update the shortcut. A DHCP reservation or a stable local hostname avoids this. On a Fritz!Box network, the configured receiver may be reachable as http://dm520.fritz.box:8088.

A channel or recording does not play

Check the provider subscription and use the channel's stream check. A probe temporarily uses one provider connection. Codec, audio and seeking support depend on the receiver/player. M3U catch-up requires real provider recordings; Xtream account and Stalker archive integrations are planned.

Reporting a problem

Record the step where it failed, receiver model/image, Dreaminator version and exact error. Include a screenshot or redacted log if useful. Remove passwords, provider stream URLs, MAC addresses and API keys before sharing.

For service diagnostics over SSH:

/etc/init.d/dreaminator restart
tail -n 100 /tmp/dreaminator.log
