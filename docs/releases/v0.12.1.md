# Dreaminator 0.12.1

This patch release updates the IPK installer output and package dependencies so installation via `opkg` prints clean English status messages and automatically installs `enigma2-plugin-extensions-epgimport` for EPG support.

## Choose your package

| Receiver / Image | Download | CPU / Architecture |
| --- | --- | --- |
| **Dreambox** (DM520 / OpenHDF & MIPS receivers) | `dreaminator_0.12.1_all.ipk` | MIPS little-endian, soft-float (`mipsle`) |
| **Vu+** (Uno 4K SE / openATV 7.5 & ARMv7 receivers) | `dreaminator_0.12.1_vuuno4kse.ipk` | 32-bit ARMv7 (`arm` / `GOARM=7`) |

> **Important:** The `_all.ipk` package contains the MIPS executable for Dreambox/MIPS receivers, while `_vuuno4kse.ipk` contains the ARMv7 executable for Vu+/ARM receivers. They are not interchangeable.

## What's Changed in 0.12.1

### 🛠 Packaging & EPG Integration
- **English `opkg` shell output & metadata:** Translated the `postinst` installation message and IPK `control` description in `tools/mkipk/main.go` into English.
- **Automatic EPGImport installation:** Added `Depends: enigma2-plugin-extensions-epgimport` to the IPK `control` file so `opkg` installs the EPGImport extension automatically when installing or upgrading Dreaminator.
- **Package validation:** Updated `tools/check_packages.py` to assert the `enigma2-plugin-extensions-epgimport` dependency in both MIPS and ARMv7 IPKs.

*(Includes all features from **0.12.0**: 15-language Web App & Enigma2 TV UI, automatic browser language detection, Hebrew/Arabic RTL layout, Web-to-TV language sync via `POST /api/language`, and Latin keyboard auto-selection.)*

## Install or Upgrade

1. Back up `/etc/dreaminator/` and `/etc/enigma2/` before upgrading.
2. Download the IPK matching your receiver CPU (**MIPS** `_all.ipk` or **ARMv7** `_vuuno4kse.ipk`) and `SHA256SUMS`.
3. Verify the checksum:
   - **Linux:** `sha256sum --ignore-missing -c SHA256SUMS`
   - **macOS:** `shasum -a 256 -c SHA256SUMS`
4. Install on the receiver over SSH (with internet access so `opkg` can fetch `enigma2-plugin-extensions-epgimport` if not already installed):
   ```sh
   opkg update
   opkg install --force-reinstall /tmp/dreaminator_0.12.1_<arch>.ipk
   ```
5. Restart the **Enigma2 GUI**, open **Plugins → Dreaminator**, and open `http://<receiver-ip>:8088` in your browser.
