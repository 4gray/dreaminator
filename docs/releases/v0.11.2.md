# Dreaminator 0.11.2

This release brings the current TV catalog, catch-up and receiver integrations to GitHub Releases. It replaces 0.6.0 as the recommended download.

## Choose your package

| Receiver / image | Download | CPU |
| --- | --- | --- |
| Dreambox DM520 / OpenHDF 6.4 build 137 | `dreaminator_0.11.2_all.ipk` | MIPS little-endian, soft-float |
| Vu+ Uno 4K SE / openATV 7.5 | `dreaminator_0.11.2_vuuno4kse.ipk` | 32-bit ARMv7 |

Both configurations have been tested by the maintainer; the release pipeline also checks both binaries through QEMU. The `_all.ipk` is the legacy DM520 package name, not a universal binary. Do not install it on the Vu+ Uno 4K SE. Other receivers and images remain unverified.

## Since 0.6.0

- Native TV catalog with live channels, movies/series from Stalker portals, search, favorites, recents and optional TMDB metadata.
- Daily programme guide and M3U catch-up; archive entry from the receiver's channel-list menu and optional EPG-key integration.
- EPGImport-compatible IPTV references for OpenHDF/openATV and fixes for protected-channel authorization and returning from archive playback.
- Separate DM520/MIPS and Vu+ Uno 4K SE/ARMv7 packages, with shared HD and Full HD artwork.
- Modular Stream logo across the README, web/home-screen icons and Enigma2 screens.
- English documentation, MIT license, dependency notices and automated test/build/release workflows.
- Go 1.26.10 minimum for the crypto/x509 fix GO-2026-6809, while retaining the earlier DM520 startup fix.

## Install or upgrade

1. Back up `/etc/dreaminator/` and `/etc/enigma2/` if upgrading.
2. Download the matching IPK and `SHA256SUMS`. Verify its SHA-256 checksum.
3. Install from a FAT32 USB drive using **Menu → Setup → Software management → Install local extension**, or copy the IPK to `/tmp` and run `opkg install /tmp/<matching-package>.ipk` over SSH.
4. Restart the **Enigma2 GUI**. Open **Plugins → Dreaminator**, then visit `http://<receiver-address>:8088` from your tablet or computer.

See the [installation guide](https://github.com/4gray/dreaminator/blob/main/docs/installation.md) for separate Dreambox and Vu+ steps, EPGImport setup and optional archive hotkeys. The attached PDF is the Windows/USB walkthrough. Installing over a previous version retains playlists and lists.

## Scope and limitations

Application labels currently use Russian. The web interface has no login and is intended for a trusted home network; keep port 8088 private. M3U catch-up depends on provider recording availability. Xtream-account and Stalker archive support remain planned. Codec, audio, seeking and physical-remote behavior depend on receiver firmware/player and provider; simulator success does not certify every combination.

Release checks cover Go vet/tests, Node regressions, Python 2.7/3 harness and simulator integration, deterministic artwork, IPK contents/CPU/version and QEMU startup of both binaries. The current source and dependency scan found no reachable vulnerabilities after the compiler update. See [development](https://github.com/4gray/dreaminator/blob/main/docs/development.md) for reproduction commands.
