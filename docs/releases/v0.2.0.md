# Dreaminator 0.2.0

The first Dreaminator version for Dreambox DM520/OpenHDF/Enigma2: manage IPTV playlists and favorites from a tablet browser.

> Historical release. This package predates the DM520 startup fixes and current TV catalog. Follow the [current installation guide](https://github.com/4gray/dreaminator/blob/main/docs/installation.md) when choosing a package. The attached English Windows guide describes current setup guidance, not a rebuilt historical binary.

## Installation

The original package is `dreaminator_0.2.0_all.ipk`. Original installation methods:

- **USB:** copy to a FAT32 drive → Menu → Setup → Software management → Install local extension.
- **From source over SSH:** `make deploy HOST=<receiver-address>` (builds the checkout's version).
- **Manual:** copy the package to `/tmp`, then run `opkg install /tmp/dreaminator_0.2.0_all.ipk`.

Open `http://<receiver-address>:8088` after installation. See the attached English Windows guide and the version warning above.

## Features

- M3U URL, M3U file upload and Xtream Codes account.
- Custom channel lists, stars, drag ordering and **Send to TV** as ordinary receiver bouquets; existing satellite bouquets retained.
- Immediate **On TV** tuning with standby wake.
- XMLTV filtering for selected channels using `tvg-id`, name and `tvg-name`; multiple EPG sources, `tvg-shift` and EPGImport integration.
- Overnight playlist and EPG refresh.

## Verification at release time

- Tests and virtual Dreambox (`make sim`) with the same package under MIPS32 emulation and simulated Enigma2/OpenWebif/EPGImport.
- Not yet run on the real DM520 at release time; follow-up in the [roadmap](https://github.com/4gray/dreaminator/blob/main/ROADMAP.md).
