# Dreaminator 0.12.2

This release completes the localization of server-generated dates, subscription expiry notices, and stream diagnostics across all **15 supported languages**, and adds a clear, step-by-step **EPG-Importer** setup guide directly inside the Web App (**Settings → Program guide (EPG)**).

## Choose your package

| Receiver / Image | Download | CPU / Architecture |
| --- | --- | --- |
| **Dreambox** (DM520 / OpenHDF & MIPS receivers) | `dreaminator_0.12.2_all.ipk` | MIPS little-endian, soft-float (`mipsle`) |
| **Vu+** (Uno 4K SE / openATV 7.5 & ARMv7 receivers) | `dreaminator_0.12.2_vuuno4kse.ipk` | 32-bit ARMv7 (`arm` / `GOARM=7`) |

> **Important:** The `_all.ipk` package contains the MIPS executable for Dreambox/MIPS receivers, while `_vuuno4kse.ipk` contains the ARMv7 executable for Vu+/ARM receivers. They are not interchangeable.

---

## What's Changed in 0.12.2

### 🌐 Complete Server-String Localization (Web App & TV UI)
- **Subscription & expiry dates:** Translated `"до <date>"`, `"«Source» до <date>"`, `"без срока"`, and `"неактивна"` into all 15 languages in both the Web App (`web/static/i18n.js`, `web/static/app.js`) and the Enigma2 TV interface (`plugin/Dreaminator/ui_i18n.py`).
- **Timestamps & status lines:** Translated full Russian server timestamps (e.g. `"15 ноября в 04:00"`), source reachability checks, stream probe warnings (including the GStreamer 4097 notice), and API error messages.

### 📺 Built-in Non-Technical EPG-Importer Guide (Port 8088)
- Expanded the **Settings → Program guide (EPG)** instructions (`open` by default) into **5 simple, non-technical steps** in all 15 languages, covering:
  1. Opening **EPG-Importer** on Dreambox (**Menu → Plugins → EPG-Importer**) and Vu+ / openATV (**Menu → Setup → EPG → EPG-Importer**),
  2. Enabling the **Dreaminator** source (**Blue** → **OK** → check **Dreaminator** → **Green**),
  3. Running an immediate import (**Yellow → Manual → OK**),
  4. Waiting 1–2 minutes for programmes to appear in the TV channel list and OpenWebif,
  5. Enabling daily automatic import.

*(Includes all features from **0.12.0–0.12.1**: 15-language Web App & Enigma2 TV UI, automatic browser language detection, Hebrew/Arabic RTL layout, Web-to-TV sync, English `opkg` installer output, and automatic `enigma2-plugin-extensions-epgimport` dependency.)*

## Install or Upgrade

1. Back up `/etc/dreaminator/` and `/etc/enigma2/` before upgrading.
2. Download the IPK matching your receiver CPU (**MIPS** `_all.ipk` or **ARMv7** `_vuuno4kse.ipk`) and `SHA256SUMS`.
3. Verify the checksum:
   - **Linux:** `sha256sum --ignore-missing -c SHA256SUMS`
   - **macOS:** `shasum -a 256 -c SHA256SUMS`
4. Install on the receiver over SSH:
   ```sh
   opkg update
   opkg install --force-reinstall /tmp/dreaminator_0.12.2_<arch>.ipk
   ```
5. Restart the **Enigma2 GUI**, open **Plugins → Dreaminator**, and open `http://<receiver-ip>:8088` in your browser.
