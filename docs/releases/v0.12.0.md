# Dreaminator 0.12.0

This release introduces **full multi-language support (15 languages)** across both the Web App and the Enigma2 TV interface, with **automatic browser language detection**, **RTL layout support**, and **automatic Web-to-TV language synchronization**.

## Choose your package

| Receiver / Image | Download | CPU / Architecture |
| --- | --- | --- |
| **Dreambox** (DM520 / OpenHDF & MIPS receivers) | `dreaminator_0.12.0_all.ipk` | MIPS little-endian, soft-float (`mipsle`) |
| **Vu+** (Uno 4K SE / openATV 7.5 & ARMv7 receivers) | `dreaminator_0.12.0_vuuno4kse.ipk` | 32-bit ARMv7 (`arm` / `GOARM=7`) |

> **Important:** The `_all.ipk` package contains the MIPS executable for Dreambox/MIPS receivers, while `_vuuno4kse.ipk` contains the ARMv7 executable for Vu+/ARM receivers. They are not interchangeable.

## What's New & Changelog

### 🌐 15-Language Localization (Web App & Enigma2 TV UI)
Both the browser interface and the Enigma2 on-screen TV catalog are now translated into **15 languages**:
- Portuguese (`pt`), French (`fr`), Hebrew (`he`), Arabic (`ar`), Italian (`it`), German (`de`), Spanish (`es`), Polish (`pl`), English (`en`), Japanese (`ja`), Chinese (`zh`), Thai (`th`), Turkish (`tr`), Czech (`cs`), and Russian (`ru`).

### 🧭 Automatic Browser Language Detection & RTL
- **Browser auto-detection (`auto` mode):** Opening the Web App automatically selects the language configured in your browser (`navigator.languages` / `navigator.language`) and updates dynamically on `languagechange`.
- **Quick language switcher:** Added a compact language selector in the top bar and in **Settings**, allowing manual override at any time.
- **RTL layout:** Added automatic `dir="rtl"` handling and RTL CSS styling for **Hebrew** (`he`) and **Arabic** (`ar`).
- **Locale-aware formatting:** Implemented per-language pluralization rules (`channels`, `entries`, `sources`, `days`) and localized date/time formatting.

### 📺 Web-to-TV Synchronization & Enigma2 Plugin Updates
- **Backend sync API:** Added `Settings.Language`, `NormalizeLanguage`, `Summary.Language`, and `POST /api/language` so the active Web App language is persisted in `/etc/dreaminator/state.json` and picked up by the Enigma2 plugin.
- **Enigma2 TV UI (`ui_i18n.py`):** Localized all TV screens (`DreaminatorScreen`, `Shell`, `DetailScreen`, `SearchPanel`, `GuideScreen`, `AboutScreen`, `BouquetArchiveScreen`, `EPG` key entry), runtime status/error messages, duration/day labels, and server-originated status fragments, while maintaining full **Python 2.7 and Python 3** compatibility.
- **Smart on-screen keyboard:** The TV search keyboard automatically starts on the Latin (`ABC`) layout for non-Russian UI languages while keeping layout switching (`ABC` / `123` / `АБВ`).

### 🧪 Testing & Quality Assurance
- Added `web/i18n.test.mjs` covering all 15 dictionaries, placeholder parity, browser language detection, RTL flags, and `receiverUI` localization.
- Added Go unit and HTTP endpoint tests (`TestLanguageSettings`, `TestLanguageEndpoint`) for language normalization, persistence, and `/api/language`.
- Added Python `I18nTests` in `tools/plugin-harness/test_shell.py` verifying all 15 plugin dictionaries, format specifiers, and HD/Full-HD skin widget bounds (`check_bounds`).

## Install or Upgrade

1. Back up `/etc/dreaminator/` and `/etc/enigma2/` before upgrading.
2. Download the IPK matching your receiver CPU (**MIPS** `_all.ipk` or **ARMv7** `_vuuno4kse.ipk`) and `SHA256SUMS`.
3. Verify the checksum:
   - **Linux:** `sha256sum --ignore-missing -c SHA256SUMS`
   - **macOS:** `shasum -a 256 -c SHA256SUMS`
4. Install on the receiver:
   - Copy to a FAT32 USB drive and use **Menu → Setup → Software management → Install local extension**, **or**
   - Copy to `/tmp` and run over SSH:
     ```sh
     opkg install --force-reinstall /tmp/dreaminator_0.12.0_<arch>.ipk
     ```
5. Restart the **Enigma2 GUI**, open **Plugins → Dreaminator**, and access the Web App at `http://<receiver-ip>:8088` (automatically displayed in your browser's language).
